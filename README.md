# KROFTON s.r.o. – web

New website for KROFTON s.r.o., stavební firma, Praha 5 – Smíchov (preview, pass 1: homepage).

```sh
npm install
npm run dev          # http://localhost:4321
npm run build        # static page + Node server in dist/
npm start            # node dist/server/entry.mjs (PORT, HOST)
```

Enquiry form settings: see `.env.example`. Details, decisions and open items: `docs/WEBSITE.md`.
